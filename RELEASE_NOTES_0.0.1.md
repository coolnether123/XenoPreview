# XenoPreview 0.0.1

## Added

- Optional Spine integration; Spine is not required to load or use XenoPreview.
- Persistent settings for preview enablement, startup state, window position, rotation, size, clothing, and tattoos.
- Full Spine Alt-click navigation from the preview window, pawn portraits, rotation controls, reroll/lock controls, and clothing/tattoo buttons.
- Automatic legacy or Spine-enabled payload selection through `LoadFolders.xml`.

## Compatibility

- Supports RimWorld 1.4, 1.5, and 1.6.
- The release package includes both legacy and Spine-enabled payloads for each supported RimWorld version.
